### Gradient Studio

  an interactive tool for creating, previewing, and exporting custom CSS gradients. Users can choose between linear, radial, conic, or repeating formats, adjust angle and position, add up to 4 colors with opacity and position, apply visual effects (pixelated, scanlines, dots, grain), copy the generated CSS code, save styles to a local gallery, and export gradients as CSS or JSON files.
